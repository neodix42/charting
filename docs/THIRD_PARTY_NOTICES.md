A separately installed Java 17+ runtime is required; builds use a JDK 17+ and keep SDK compile dependencies outside the release archive.

Provider data is fetched directly for local display or user-requested CSV downloads; workspace exports contain configuration only. JForex credentials are stored separately for authenticated market data. There are no trade-execution, telemetry or hosted data redistribution components.
